# 壁の編集

管理者はBで建築モードを開始し、床をクリックして壁を配置します。Rで90度回転し、壁にカーソルを合わせてマスをクリックすると開口／復元を切り替えます。ホイールまたは上下キーで、選択した壁の高さを50cmずつ変更できます。Delで壁全体を削除し、右クリックまたはEscで終了します。

初期マップには編集可能な壁2枚と1mの木箱2個があります。建築モードで対象にカーソルを合わせ、Delで個別に削除できます。試合開始・リセットや床の再校正では残りのマップオブジェクトを維持し、床の移動・回転に追従します。サイズ変更で新しい床に収まらないものは取り除かれます。木箱も弾を遮ります。

管理壁は幅160cm・厚さ16cm。初期高さは200cmで、横3マス、高さ50cm単位の最大8段です。高さを縮めても隠れた段の編集状態は保持され、再び伸ばすと戻ります。床面と配置範囲、壁の総数、追加する部分の重なりはサーバーで検査します。

壁のマスと高さはサーバーが一体の状態として同期します。開口に対応する弾の衝突ボックスも無効になり、復元すると再び遮ります。開口を狙っても壁の平面を選択できるため、空いたマスをクリックして戻せます。プレイヤーが使用する短時間の壁は従来どおりです。管理操作には有効な管理者権限が必要です。

サーバー・Quest・観戦クライアントは同じ network protocol 14 のビルドを使用してください。protocol 13 の配布物とは接続できません。
