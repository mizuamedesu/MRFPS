# 操作と接続

デスクトップの **F1** で接続・設定パネルを開きます。サーバー欄へ `ホスト名:ポート` または `IP:ポート` を入力し、「Join as player」か「Join as inspector」を選びます。既定値は `127.0.0.1:7777`。最後の有効な接続先をローカルのGameUserSettingsに保存します。

パネルからアリーナ位置合わせ、MoBits接続、明示ARM、STOPを操作できます。MoBitsは「Connect MoBits」で接続後、装着者の校正済みプリセットを準備してから「ARM」を押します。観戦者はPlayer 1・Player 2・Free viewを選択できます。

観戦の既定表示は **PLAYER POV** です。**1 / 2** または設定パネルでP1 / P2を選び、**M**で両者のパネルを表示します。映像がない場合は送信待ち・共有停止・受信状態を表示します。**V**で同期poseに基づく **3D RECONSTRUCTION** へ切り替えられます。プレイヤーは **X** で自分のゲーム画面の共有を開始・停止できます。QuestではOSの共有許可が必要です。Windowsでは自身のゲーム画面とHUDを共有します。実写passthroughを含むQuest映像が観戦画面へ届く実統合は、まだ検証完了していません。

| 自分のゲーム画面の共有開始・停止 | X | 左X。QuestではOSの共有許可が必要 |
| 壁を立てる | Q | 左手を下から上へ引き上げる |
| ミニ盾 | Eを押している間 | 左手をパーにする |
| MoBits ARM | H / 設定パネル | 右A |
| MoBits STOP | Escape / 設定パネル | 右B |
| 設定パネル | F1 | デスクトップ操作用 |
| 観戦フリー視点 | Tab / 設定パネル | デスクトップ操作用 |
| 観戦プレイヤー視点切替 | Space | デスクトップ操作用 |
| 観戦P1 / P2を選択 | 1 / 2 / 設定パネル | デスクトップ操作用 |
| 観戦同時表示 | M | デスクトップ操作用 |
| Quest映像 / 3D再描画の切替 | V | デスクトップ操作用 |

パネルを開くと射撃・ミニ盾・MoBits出力を停止し、マウスで操作できます。Close / F1でゲーム操作に戻ります。EscapeはMoBits停止を要求してからパネルを閉じます。MoBitsの準備と確認範囲は [MoBits.md](MoBits.md) を参照してください。

観戦中のEscapeは、マウスをウィンドウ内へ固定せずに解放します。解放中はマウスやスティックでカメラを回せず、WASD / R / Fでも移動しません。画面内の左クリックで操作を再開します。設定パネル上のクリックでは再取得せず、パネルを閉じた後も直前の解放状態を維持します。プレイヤーのEscapeによるMoBits STOPは従来どおりです。

デスクトップのプレイヤー視点は、マウスを上へ動かすと上を向きます。観戦フリーカメラの縦入力は既存のコントローラー設定を維持します。自分のプレイヤー情報ラベルは一人称のワールド描画から除外し、カメラ前の重複した3Dステータス文字も表示しません。自分の状態は通常HUDで、他プレイヤーのラベルは外側からの観戦で確認できます。これはゲームの通常描画仕様で、共有映像の後処理による隠蔽ではありません。
