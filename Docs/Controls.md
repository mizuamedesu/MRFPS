# 操作

## 観戦・管理

| 操作 | キー |
| --- | --- |
| メニュー | F1 |
| 管理パネル | F2（管理者） |
| P1 / P2の映像 | 1 / 2 |
| 自由視点 | Tab |
| 映像と仮想空間の表示切替 | V |
| 二人の同時表示を切替 | M |
| マウスを解放・操作停止 | Esc |
| 自由視点の移動 | WASD / E / Q |

## 建築（管理者）

| 操作 | キー |
| --- | --- |
| 建築を開始・終了 | B |
| 壁・床・階段・箱 | 1 / 2 / 3 / 4、ホイール |
| 設置 | 左クリック（長押しで連続） |
| 回転 | R |
| 選んだ建築を削除 | Del |
| 建築を終了 | 右クリック / Esc |

緑のプレビューは設置可能、赤は設置不可です。床に沿った50cmのグリッドと90度回転を使います。床の範囲外、他の物体への重なり、設置数の上限はサーバーでも検査します。

管理パネルで開始・一時停止・再開・リセット、床のサイズ変更と位置の校正を操作できます。初期床は幅4.5m・長さ7m（長さがY軸）です。「床の位置調整」を押した瞬間の二人の中点を床の中心とし、P1→P2が+Yになります。歩行に床は追従せず、二人の間隔で伸縮しません。

## プレイヤー

| 操作 | デスクトップ | Quest / ハンド |
| --- | --- | --- |
| 発射 | 左クリック | 右トリガー / ContactGloveの右人差し指 |
| 共有原点を登録 | C / メニュー | 左Y。共有原点に立ち、同じ正面を向く |
| 自分のゲーム画面を共有・停止 | X | 左X。Questの画面共有はOSの許可が必要 |
| 壁 | Q | 左手を下から上へ上げる |
| ミニ盾 | E長押し | 左手を開く |
| MoBitsを有効化 | H / メニュー | 右A |
| MoBitsを停止 | Esc / メニュー | 右B |

MoBitsは接続後、装着者と調整済みプリセットの準備を確認してから有効にします。[MoBits.md](MoBits.md)を参照してください。メニューを開くと射撃・盾・MoBitsを停止します。観戦のEscはカーソルを解放し、画面内のクリックでカメラ操作へ戻れます。建築中はカーソルで配置し、WASDとE/Qでカメラを移動します。

Questでは他のキャストを閉じ、MRFPSの共有を使います。実写パススルーを含む映像と、追跡姿勢から描く立体視点は別の表示です。到達した実機確認の範囲は[Handoff.md](Handoff.md)に記録します。
