# 操作

## 観戦・管理

| 操作 | キー |
| --- | --- |
| メニュー | F1 |
| 管理パネル | F2（管理者） |
| P1 / P2の映像 | 1 / 2 |
| プレイヤー映像を別窓で開く | Escでマウスを解放し、画面上部の「P1 別窓」 / 「P2 別窓」 |
| 2つ目の自由視点を別窓で開く | Escでマウスを解放し「観戦 別窓」 |
| 自由視点 | Tab |
| 映像と仮想空間の表示切替 | V |
| 二人の同時表示を切替 | M |
| マウスを解放・操作停止 | Esc |
| 自由視点の移動 | WASD / E / Q |

## 建築（管理者）

| 操作 | キー |
| --- | --- |
| 建築を開始・終了 | B |
| 壁を置く | 床を左クリック（長押しで連続） |
| 穴を開ける / 戻す | 壁のマスを左クリック |
| 壁の高さを変える | 壁にカーソルを合わせ、ホイール / ↑ / ↓ |
| 回転 | R |
| 壁を削除 | 壁にカーソルを合わせ、Del |
| 建築を終了 | 右クリック / Esc |

緑のプレビューは設置可能、赤は設置不可です。壁は横3マス、高さ50cm単位で0.5〜4mに変更できます。壁面をクリックするとそのマスの開口と復元を切り替えます。短くした壁を再び高くすると、隠れていたマスの編集状態も戻ります。床に沿った50cmの配置グリッドと90度回転を使います。床の範囲外、衝突判定を持つ物体への重なり、設置数の上限はサーバーでも検査します。

初期マップの木箱と壁も、建築モードでカーソルを合わせてDelで削除できます。木箱に合わせると「木箱」と表示され、弾も遮ります。

管理パネルで開始・一時停止・再開・リセット、床のサイズ変更と位置の校正を操作できます。初期床は幅4.5m・長さ7m（長さがY軸）です。「床の位置調整」を押した瞬間の二人の中点を床の中心とし、P1→P2が+Yになります。歩行に床は追従せず、二人の間隔で伸縮しません。

## プレイヤー

| 操作 | デスクトップ | Quest / ハンド |
| --- | --- | --- |
| 銃 | 開始時に所持 | 最初から右手に装備し、手を開いても離れない |
| 発射 | 左クリック | 右トリガー / ContactGloveの右人差し指 |
| リロード | R | 左手を弾倉のそばで上下にスライド |
| 共有原点を登録 | C / メニュー | 左Y。共有原点に立ち、同じ正面を向く |
| 結果を確認して次へ | 結果表示中に Y | 結果表示中に左Y。Bot戦は本人、1対1は両者の操作で続行 |
| 自分のゲーム画面を共有・停止 | X | 左X。Questの画面共有はOSの許可が必要 |
| 壁を出す | Q | 左手を下から上へ上げる |
| 自分の壁を消す | — | 左手を上から下へ下げる |
| ミニ盾 | E長押し | 左手を握る（ContactGlove） |
| MoBitsを有効化 | H / メニュー | 右A |
| MoBitsを停止 | Esc / メニュー | 右B |

MoBitsは接続後、装着者と調整済みプリセットの準備を確認してから有効にします。[MoBits.md](MoBits.md)を参照してください。メニューを開くと射撃・盾・MoBitsを停止します。観戦のEscはカーソルを解放し、画面内のクリックでカメラ操作へ戻れます。建築中はカーソルで配置し、WASDとE/Qでカメラを移動します。

銃はMRピストル、装弾数30発、予備弾薬は無限です。銃名・残弾・自分のHPはプレイヤー画面の中央下に、相手のHPゲージは相手の頭上に表示されます。プレイヤーに与えたダメージだけを、命中位置に滑らかに現れて消える数字で表示します。連続して同じ場所に命中した数字は重ねずに更新します。召喚した壁とステージの壁は弾を遮り、銃では壊れません。Questでは両手の位置をコントローラー優先で追跡し、指の曲がりと開きをContactGloveから取得します。グローブが未接続・古い状態ではQuestの指の値に切り替えません。銃は常に右手に装備され、位置を追跡できない間は隠れ、追跡が戻ると再表示されます。発射時の銃口表示はローカルで即座に出し、弾数・リロード・命中と壁の生成・削除はサーバーで処理します。手を下げると自分が最後に出した壁から消え、管理者の壁や木箱は消えません。

別窓はP1・P2と自由視点をそれぞれ1つずつ開けます。自由視点の別窓をクリックして選択し、WASD / E / Qで移動、右クリックを押しながらマウスを動かして視点を変更します。Escまたは右クリックを離すとマウスを解放します。ウィンドウを閉じても観戦接続は続きます。別々のPCから操作する場合は、それぞれ異なるトークンで観戦クライアントを起動してください。

Questでは他のキャストを閉じ、MRFPSの共有を使います。実写パススルーを含む映像と、追跡姿勢から描く立体視点は別の表示です。到達した実機確認の範囲は[Handoff.md](Handoff.md)に記録します。

認証接続後は試合開始前でも射撃・盾・壁を使えます。練習中の弾は他プレイヤーにダメージを与えません。Questでは接続時に共有許可が表示されます。自動要求を止める場合は起動オプションに `-MRFPSNoAutoCapture` を指定し、必要なときに左Xで共有します。接続が切れたときは「接続待ち」が表示され、未使用の認証トークンが供給されると再接続を試みます。

プレイヤーのHP・弾数は視線の中心より下に表示されます。対人戦のプレイヤー画面では仮想アバターを表示せず、Bot 戦では相手の Bot を表示します。観戦画面には両プレイヤーを表示します。
