# Quest の MoBits

Quest 版は [MoBits UE5 SDK](https://github.com/MoBits-Project/UE5_SDK) の Quest スタンドアローン版 `2aba57a51923fb2252347407f023db8457e05804` を使用します。MoBits の別アプリ、PC、ADB 中継を使わずに、Quest 本体の Bluetooth で左右の EVT5 に接続します。

同じ機器を別の MoBits アプリでも使用している場合は、そちらのセッションを安全に停止してからゲームに接続します。機器の登録情報はゲームごとに保存されるため、初回登録はゲーム内で行います。

エラー 144 は操作時の状態が条件に合わないことを表します。画面に表示される案内を確認し、候補が古い場合は「機器を探す」から選び直します。原因の特定には `tools/automation/control.py` の `status` が返す `quest_mobits_message` も参照できます。

## ゲーム内の準備

サーバーにプレイヤーとして参加してから、右スティックを押し込んで「MoBits 設定」を開きます。右トリガーのポインターで操作し、停止する場合は右 B または画面の「停止」を押します。

1. 「開始・権限」を押し、付近のデバイスの権限を許可します。権限ダイアログから戻ったらもう一度「開始・権限」を押します。
2. 「機器を探す」を押します。初回は EVT5 をペアリングモードにし、候補を選んで「接続・登録」を押します。左右それぞれ接続済みになったら、別々の機器を左腕・右腕に割り当てます。
3. 両上腕に電極 1・2 を装着し、機器の USB を外してから「装着と左右を確認して開始」を押します。両機器の充電が 10%以上で、対応ファームウェアが必要です。
4. 「校正を開始」し、片腕ずつ弱いパルスから少しずつ調整します。本人が感じ始めた値を記録し、実際に届いた快適な値をその腕の上限として確定します。左右両方を確定して波形を準備します。
5. 左右の腕でそれぞれ4種類の波形を試し、本人が快適だったものを確定します。全8項目の確認後に有効化し、画面を閉じてゲームへ戻ります。

設定・確認・有効化は装着者の操作で行います。ゲームイベントは有効化を行わず、確認前の刺激も再生しません。中断・画面離脱・接続断の後は停止状態を確認し、新しいセッションから再設定します。

## 射撃・被弾

サーバーが確定した発射ごとに右上腕の Gun Recoil、被弾時に左上腕の Damage を、本人が有効化したローカルセッションに要求します。別のプレイヤーや観戦者には送りません。接続パネルの表示中はゲームイベントの刺激を送りません。

SDK の物理出力間隔・使用量の制限により、短い間隔の連射では一部の刺激要求が見送られます。期限切れの要求を後からまとめて再生しません。Quest のバックグラウンド移行、ヘッドセットの取り外し、ゲーム停止・終了時は停止し、再接続で勝手に有効化しません。

## 開発用 SDK の取得

SDK は非公開リポジトリから `.local/mobits-sdk` に取得し、ゲーム内に組み込みます。Windows の `Scripts/Build-MRFPS.ps1` と Mac の `Scripts/mac/build.sh` は、初回ビルド時に `tools/mobits/ensure_sdk.py` を実行します。Git で上記リポジトリを読み取れる認証が必要です。固定コミットと Android ライブラリの SHA-256 を検証し、非公開の SDK 本体をこのリポジトリへ複製しません。

SDK 0.7.0 はプレビュー版で、上腕2台と固定4波形を対象とします。身体トラッキング、他部位、壁生成、OTA はこのスタンドアローン経路では提供されません。Quest 実機では１台の接続を確認しています。２台同時の接続と身体への出力は未確認です。
